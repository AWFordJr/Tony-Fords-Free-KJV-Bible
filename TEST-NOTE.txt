What was trimmed for the slim Linux AppImage (version still 1.0.0; no feature cut for Bible use)
  - Explicit bundle.linux.appimage.bundleMediaFramework = false (GStreamer plugins were never bundled; HTML5 Music uses system codecs)
  - Deduped duplicate SONAME library copies (librsvg/libgio/etc.)
  - Removed packaged docs
  - Replaced unused WebKit image codecs with tiny stubs: libavif + AV1 encoder deps (libaom/librav1e/libSvtAv1Enc/libgav1) and libjxl
  - Stubbed unused flite voice data libs WebKit links but this app never calls (kept real flite core + en_US voices WebKit registers)
  - Read-aloud still uses speechSynthesis / system voices (espeak-ng or speech-dispatcher on Linux)
  - Music tab unchanged (HTML5 Audio / internet radio; needs system GStreamer plugins like any normal Linux desktop)
  - No AVIF/JPEG-XL image decode inside the WebView (app never uses those formats)
